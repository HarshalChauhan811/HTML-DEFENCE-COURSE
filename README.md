# 📘 **Lecture 01 — HTML Basics**
### 🔹 *Foundation of the Web*
- 🌍 **HTML = HyperText Markup Language**
- 🔗 Hypertext → Linked pages (navigation)
- 🏷 Markup → Tags give structure and meaning   
- 🛠 **Setup:** VS Code + Live Server + Prettier
- ✏️ **Core Tags:** `<h1>`–`<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`
- 📏 **Spacing:** `<br>`, `<hr>`
- 🎯 **Best Practices:** One `<h1>`, proper hierarchy, always use `alt` in images

# 📘 **Lecture 02 — Nested Lists & Tables**
### 🔹 *Organizing Data Like a Pro*
- 📝 **Nested Lists:** UL inside UL, OL inside UL, mixed lists allowed
- 🧩 Example:
  - India
    - Delhi
    - Mumbai
- 📊 **Tables:** `<table> → <tr> → <th>/<td>`
- 🏢 Professional structure: `<thead>`, `<tbody>`, `<tfoot>`
- ➕ **Advanced:** `colspan`, `rowspan` for merging cells

# 📘 **Lecture 03 — File Paths, Boilerplate, DIV**
### 🔹 *Project Structure + HTML Engine Room*
- 🗂 **Relative Paths (MOST IMPORTANT):**
  - Same folder → `file.jpg`
  - Go inside folder → `images/logo.png`
  - Go up → `../photo.png`
- 🌐 **Absolute Paths:** External URLs only
- 🧱 **Boilerplate Template:** UTF-8, viewport meta, title
- 🧩 **Layout Elements:**
  - `<div>` → block group
  - `<span>` → inline
  - `class` → reusable
  - `id` → unique
- 🧭 **Semantic Tags:** `header`, `main`, `footer`, `nav`, `section`, `article`

# 📘 **Lecture 04 — HTML Forms (Master Level)**
### 🔹 *Inputs, Validation, Backend Flow*
- 🧾 **Form Skeleton:** `<form action="" method="POST"></form>`
- 🔤 **Input Types:** text, password, email, number, date, file
- 🎚 **Special Inputs:** range, color, url, search, tel
- 🕹 **Choice Inputs:**
  - Radio → single choice (same `name`)
  - Checkbox → multiple options
- 📝 **Select & Textarea** for dropdown & long text
- 🎯 **Critical Rules:**
  - `id` ↔ `for` = connection
  - `name` = backend key
  - `value` = actual data sent
- 🔐 **Validation:** required, pattern, placeholder
- 🔁 **Data Flow:** Form → Browser → name=value → Backend → Database

# 📘 **Lecture 05 — Media, Multi-Page Sites & Deployment**
### 🔹 *Videos • Audio • YouTube • Website Deployment*

## 🎥 **Video Tag**
- `<video src="" controls>` → Basic player
- 🔇 Autoplay = `autoplay muted`
- 🖼 Poster thumbnails → `poster="thumb.jpg"`
- 🏆 **Best Method:** `<source>` for multiple formats

## 🎵 **Audio Tag**
- `<audio src="" controls>`
- Works similar to video

## 🎬 **YouTube Embedding**
- Use iframe format:
```html
<iframe src="https://www.youtube.com/embed/VIDEO_ID" allowfullscreen></iframe>
```

## 🗂 **Multi-Page Website Structure**
```
index.html
about.html
courses.html
contact.html
```
- 🔗 Navigation using `<a href="">`

## 🚀 **Deploy on Netlify**
1. Create account
2. Upload project folder
3. Site goes live automatically
